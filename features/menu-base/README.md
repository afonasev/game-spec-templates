# Базовое меню

Пакет: `menu-base`. Версия: **0.2.0**. Зависимости: нет.

Задаёт общую структуру и UX меню. Правила распространяются на главное меню, вложенные страницы, диалоги, игровые меню, настройки, справку и лабораторию при подключении этих функций.

- [Требования](requirements.md)
- [Критерии приёмки](acceptance.md)
- [Как подключить](usage.md)

Пакет не задаёт художественный стиль, состав режимов игры, механику сохранения/загрузки, лаборатории или обновления приложения. Настройки описаны в отдельном пакете [settings](../settings/README.md).

В версии 0.2.0 добавлены MENU-ACTIONS-01–03: краткие понятные подписи, отсутствие дублирующих действий и один переключатель для обратимого признака. Правило общей позиции «Назад» остаётся в MENU-LAYOUT-01.
