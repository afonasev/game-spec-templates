# Как подключить базовое меню

Это инструкция для проекта, подключающего `menu-base`. Заполненное описание хранится в репозитории игры.

1. Зафиксируйте версию пакета и commit репозитория шаблонов.
2. Укажите платформы, поддерживаемые устройства и минимальные размеры/пропорции экранов.
3. Определите основные игровые действия и дополнительные маршруты. Для каждого маршрута укажите доступность и точку возврата.
4. Укажите действия, их короткие понятные подписи и области действия; исключите дубли. Для обратимого признака предусмотрите один переключатель с видимым состоянием. Опишите необходимость shortcuts, дублирующих доступный выбор.
5. Выберите общую компоновку повторяющихся действий и её адаптивные варианты в стиле игры.
6. Опишите начальный фокус, переходы, восстановление контекста и внутренние прокручиваемые области.
7. Укажите дополнительные shortcuts геймпада и их доступность. Базовые подтверждение/возврат сохраняются.
8. Определите правила локальной и сетевой паузы, владельца общего или личного меню.
9. Запишите согласованные отклонения и проверьте [критерии приёмки](acceptance.md).

## Пример описания в проекте

```markdown
# Подключение меню

Пакет: menu-base 0.2.0.
Ревизия шаблонов: <точный commit>.
Платформы: Windows, macOS.
Устройства: мышь/клавиатура, геймпады Xbox/PlayStation/Switch.
Поддерживаемые окна: <диапазон размеров и пропорций>.

Основные действия: локальная гонка, сетевая игра.
Дополнительные маршруты: рекорды, настройки.
Начальный фокус: локальная гонка.

«Назад» находится в общей верхней панели всех вложенных страниц.
Оболочка экрана не прокручивается; прокрутка есть у списка рекордов.
При возврате из настроек восстанавливается фокус на «Настройки».

Start запускает гонку только в готовом составе на экране подготовки.
Подсказки кнопок отображаются на соответствующих действиях.
В локальной гонке игровое меню останавливает симуляцию.
В сетевой игре личное меню блокирует только ввод своего игрока.

Отклонения: нет.
```

Содержание примера не становится обязательным для других игр. Лаборатория, подготовка матча, обновления и сохранения получают собственные требования.
