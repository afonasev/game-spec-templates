# Каталог параметров

Версия: **0.1.0**. Этот документ раскрывает LAB-CATALOG-01/02 и LAB-GROUPS-01, не задавая одинаковые параметры всем играм.

## Метаданные

| Поле | Контракт |
|---|---|
| Ключ | Стабильная идентичность параметра; смена подписи не меняет ключ |
| Тип | Целое/дробное число, переключатель, перечисление либо другой объявленный тип |
| Группа | Обязательная принадлежность; вложенность и привязка к сущности зависят от игры |
| Название | Понятное человеку имя |
| Описание | Что меняется и какие существенные границы сохраняются |
| Default | Значение поставляемой базы и однозначный источник для дополнения старых профилей |
| Допустимые значения | Для чисел minimum/maximum/step и единицы; для вариантов — стабильные ID и подписи; для текста — ограничения и подстановки |
| Связи | Проверки между полями, если есть |
| Применение | Следующая игра по умолчанию; отдельно объявленные preview/live-правила при наличии |

Одни согласованные определения используются редактором, валидацией и игровым потребителем. Конкретный способ организации кода не предписывается. Покрытие каталога проверяется относительно объявленного редактируемого состава, а не всех числовых констант приложения.

## Примеры

Значения и группы ниже иллюстративные, не требования к конкретной игре.

| Ключ | Группа | Тип | Значения | Назначение |
|---|---|---|---|---|
| combat.projectileSpeed | Юниты / Танк / Оружие | Дробное число | Default 30 м/с, 1–100, шаг 0,5 | Время долёта; не расширяет дальность выбора цели |
| combat.projectileEffect | Юниты / Танк / Оформление | Готовый эффект | spark, plasma; default spark | Внешний вид снаряда; не меняет урон и коллизию |
| ai.reactionSeconds | AI / Реакция | Дробное число | Default 0,4 с, 0,1–2, шаг 0,1 | Время реакции в рамках правил AI |
| rewards.victory | Награды | Целое число | Default 100, 0–1000, шаг 10 | Награда за победу |

Редактировать положение объекта карты через набор координат в лаборатории нельзя. Для размещения нужен отдельный пространственный инструмент. Выбор готового эффекта, материала или звукового варианта допустим, если он имеет понятный смысл и поддерживаемый игровой потребитель.

Допускаются цвета, векторы, кривые, текстовые шаблоны и ссылки на ресурсы, если игра обосновывает такой способ редактирования и предоставляет соответствующий редактор. Вектор не разрешает обходить запрет на пространственное размещение объектов карты. Preview полезен, но не обязателен для каждого поля.

## Поиск и изменения

Глобальный поиск использует группу, название, описание и ключ. Совпадение не зависит от раскрытого раздела. Результаты сохраняют контекст группы и сущности. Общий просмотр изменений показывает поле и значения «было → стало»; переход из результата к полю не сбрасывает черновик.

Дополнительные фильтры по типу, области влияния и другим признакам необязательны. Неактивные либо исключённые из лаборатории поля не должны становиться редактируемыми через обходной фильтр, поиск или diff.
