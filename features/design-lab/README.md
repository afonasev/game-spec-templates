# Лаборатория геймдизайна

Пакет: `design-lab`. Версия: **0.1.0**. Зависимость: [menu-base](../menu-base/README.md) **0.1.0**.

Лаборатория предназначена для настройки баланса, темпа, поведения и других параметров, от которых зависит интерес к игре. Допускаются осмысленные параметры оформления, например выбор готового эффекта снаряда для юнита. Пространственное размещение объектов относится к отдельному инструменту авторинга.

- [Каталог параметров и метаданные](parameter-catalog.md)
- [Жизненный цикл конфигурации](configuration-lifecycle.md)
- [Критерии приёмки](acceptance.md)
- [Подключение и пример](usage.md)

Обязательная модель включает сгруппированные параметры, поиск, черновик и diff, профили с неизменяемыми версиями, защищённый релизный каталог и пользовательские эксперименты. При каждом запуске dev- и production-клиента выбирается последняя релизная версия Default-профиля. Выбор другой сохранённой версии автоматически активирует её для последующих игр текущей сессии. Одно действие возвращает к релизному Default.

Автор в dev-клиенте создаёт версии любых профилей и управляет их включением в поставку. Все созданные человеком профили и сохранённые версии хранятся в Git проекта. В production поставляемые профили доступны только для чтения; игрок может сделать независимую копию любой версии и развивать её локально. Обновление сохраняет эти эксперименты и дополняет отсутствующие новые параметры поставляемыми defaults.

Лаборатория по умолчанию недоступна во время матча и не изменяет текущую игру. Live-применение, preview, импорт/экспорт и другие расширения подключаются по требованиям конкретной игры. `settings` не является зависимостью; предпочтения пользователя и обычная подготовка матча остаются отдельными функциями.

Пакет не задаёт движок, стиль, конкретное дерево групп или формат хранения. Документация подключения и исключения хранятся в репозитории игры. Релизная отметка не разрешает сборку, commit/push, публикацию или обновление установленного клиента.
